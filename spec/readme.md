# Goals

This project should be an IntelliJ Ultimate (only because we need tomcat run configurations that are ultimate-specific)
plugin that simplifies configuration and execution of `neo` suite projects for our organisation `Antenia`.

It should always follow best practices, good design patterns, respect separation of concerns, be modular, configurable,
maintainable and legible.

IntelliJ plugin doc can be found here:
https://plugins.jetbrains.com/docs/intellij/plugins-quick-start.html

what the plugin should be always is described in the spec folder that is the only source of truth.
Make sure it always respects it.

Avoid `hacks` and prefer using official APIs.

Configuration files should be placed in a `.local/` folder at project root.

Please always respect IntelliJ UI Guidelines and prefer conforming to standard.
